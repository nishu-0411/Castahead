# Castahead
Castahead — DAU Hackathon  |  Supply Chain Resilience &amp; Demand Prediction Models  |  Disruption-aware demand forecasting system on the M5 dataset that fused past sales, weather, black-swan events, and what-if scenarios, using an ensemble of Prophet, LightGBM, and N-BEATS to outperform individual models in accuracy and stability.

# CastAhead

An AI-powered demand forecasting system developed for retail demand prediction.

## Technologies
- Python
- LightGBM
- N-BEATS
- Prophet
- Pandas
- NumPy

## Features
- SKU-level demand forecasting
- Time-series feature engineering
- Ensemble forecasting
- WMAPE, RMSE and MAE evaluation
- Weather and external-factor integration

## Dataset
M5 Forecasting Dataset and additional external datasets.

## Project Structure
The complete source code is provided in `CastAhead.zip`.

## How to Run
1. Download `CastAhead.zip`
2. Extract the files
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run the main Python script/notebook.
