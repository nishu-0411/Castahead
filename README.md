# Castahead
Castahead — DAU Hackathon  |  Supply Chain Resilience &amp; Demand Prediction Models  |  Disruption-aware demand forecasting system on the M5 dataset that fused past sales, weather, black-swan events, and what-if scenarios, using an ensemble of Prophet, LightGBM, and N-BEATS to outperform individual models in accuracy and stability.
